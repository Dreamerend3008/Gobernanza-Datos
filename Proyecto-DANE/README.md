# Proyecto de Gobernanza de Datos

Este proyecto tiene como objetivo facilitar el acceso y gestión de datos relevantes para la gobernanza.

## Acceso a los datos

Los datos utilizados en este proyecto están disponibles en el siguiente enlace:  
[https://microdatos.dane.gov.co/index.php/catalog/833/study-description](https://microdatos.dane.gov.co/index.php/catalog/833/study-description)
No los agrego al repositorio porque son extremadamente grandes y ocuparian mucho espacio, por lo tanto solo es cuestion de descargarlos y agregarlos a la carpeta de data
